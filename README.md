# atividade-branchs

Projeto simples em HTML criado para praticar o uso de branches, commits, merges e pull requests no Git/GitHub.

## O que tem aqui

- `index.html`: página simples com o conteúdo das funcionalidades desenvolvidas durante a atividade.

## Como rodar o projeto

1. Clone o repositório:
```bash
   git clone https://github.com/Barzyx/atividade-branchs.git
```
2. Entre na pasta:
```bash
   cd atividade-branchs
```
3. Abra o arquivo `index.html` no navegador (duplo clique nele, ou clique com o botão direito no VS Code e escolha "Open with Live Server", se tiver a extensão instalada).

## Estrutura de branches

- `feature/nome-da-funcionalidade`: branches usadas para desenvolver novas funcionalidades.
- `bugfix/nome-do-bug`: branches usadas para correção de bugs.
